# Interactive Expense Tracker

A responsive browser-based expense tracker built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Add expenses with name, amount, category and date
- Edit and delete existing expenses
- Search expenses by name
- Filter by category and exact date
- Sort by newest, oldest, highest amount or lowest amount
- Calculate total expenses, current-month expenses and transaction count
- Show the total for the currently filtered expenses
- Save data in browser LocalStorage, so it remains after refreshing the page
- Responsive layout for desktop and mobile screens

## Technologies
- HTML5
- CSS3
- JavaScript (DOM manipulation, events, arrays and objects)
- Browser LocalStorage
- Git and GitHub

## Run locally
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Add an expense using the form.

No installation or backend server is required.

## Project files
- `index.html` – page structure and form
- `style.css` – responsive design and styling
- `script.js` – expense management, filtering, sorting and LocalStorage

## Data storage
Expenses are stored in the browser under the LocalStorage key `expenseTrackerData`. Data is stored only in the current browser on the current device; clearing browser site data will remove it.
